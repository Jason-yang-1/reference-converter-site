# Reference Converter website

This repository contains the generated static website and offline downloads for Reference Converter. Open the website to convert references and download an editable Word bibliography, including APA 7 formatting. Reference data is processed locally in the browser.

Offline downloads:

- [ZIP for sharing](downloads/Reference-Converter-Offline.zip): extract it, then double-click the HTML file.
- [Single-file offline app](downloads/Reference-Converter-Offline.html): save the HTML file, then open it in a browser.

The [source project](https://github.com/Jason-yang-1/reference-converter) is maintained separately and may require repository access. This deployment contains generated assets only.

Third-party attribution and license texts are available in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and [LICENSES.txt](LICENSES.txt). The offline HTML also embeds the full attribution appendix.
